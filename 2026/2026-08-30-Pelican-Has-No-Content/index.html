⚠️ 错误提示

使用官方的 pelican.yml，content 文件夹内有测试的文章 *.md，但是没有生成文章页面。

💡 错误原因

Could not import ‘markdown.Markdown’. Have you installed the ‘markdown’ package?
GitHub Actions 环境中没有安装 Markdown 支持，所以 Pelican 无法解析 .md 文件，导致处理了 0 篇文章。
