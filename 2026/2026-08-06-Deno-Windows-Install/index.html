Deno Windows 安装

📝 笔记总结

PowerShell 脚本安装最方便。

📖 内容来源

  • 安装 Deno
  • Deno Windows 安装（DeepSeek）

Deno 是一个由 Node.js 的原始作者 Ryan Dahl 创建的 JavaScript、TypeScript 和 WebAssembly 运行时。你可以把它看作是 Node.js 的“进化版”，旨在解决 Node.js 早期设计中的一些遗憾，为现代 Web 开发提供一个更安全、更高效的开发环境

在 Windows 上安装 Deno 非常简单，有多种方法可供选择。官方推荐使用 PowerShell 脚本，因为它能提供更快的启动速度。

📦 其他安装方式

如果你更习惯使用包管理器，这些也是不错的选择：

包管理器 命令
Winget winget install DenoLand.Deno
Scoop scoop install deno
Chocolatey choco install deno
npm npm install -g deno（启动性能略逊于官方脚本）

🖱️ 手动安装与系统要求

你也可以选择从 GitHub 的发布页面下载对应架构的 .zip 压缩包，解压后将 deno.exe 放在一个你方便管理的目录，并手动将其添加到系统 PATH 环境变量中。

系统要求：请确保你的 Windows 系统是 Windows 10 版本 1709 或 Windows Server 2016 版本 1709 及更新的版本。

⬆️ 更新 Deno

当你需要更新到最新版本时，只需在终端中运行deno upgrade命令即可。
