SCG (Static Code Generation) List

发表于 2026-08-14 更新于 2026-08-19

静态代码生成器（SCG）列表

📝 持续更新

"静态代码生成"在当前语境下通常指向两类工具：一是用于生成网站HTML的静态站点生成器（Static Site Generator，SSG），例如Hugo、Gatsby；二是更广义的代码生成器（Code Generator），例如T4、CodeSmith，用于生成各类编程语言的源代码。本列表主要聚焦于前者，并补充了一些其他类型的代表。

💡 同步更新：github.com/shenjuexiao/SCG-list

🔍 更多查找：jamstack.org

🍎 A

Amazon CodeWhisperer

  • 技术栈：多种编程语言，AI
  • 官方网站：aws.amazon.com/cn/codewhisperer
  • 项目地址：商业产品
  • Demo：aws.amazon.com/cn/codewhisperer/resources

Astro

  • 技术栈：Astro (多框架兼容)
  • 官方网站：astro.build
  • 项目地址：github.com/withastro/astro
  • Demo：astro.build/showcase

🐈 C

CodeSmith

  • 技术栈：.NET，C#
  • 官方网站：codesmithtools.com
  • 项目地址：商业软件
  • Demo：codesmithtools.com/generator
